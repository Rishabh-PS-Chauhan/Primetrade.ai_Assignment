# Primetrade.ai_Assignment
# Scalable Web App – Frontend Developer Task

A modern, scalable full-stack web application with authentication, profile management, and a crypto-style dashboard.  
Built as part of the **Frontend Developer Intern assignment**.

---

## 🚀 Live Overview

This project demonstrates:
- Secure authentication using JWT
- A polished Web3-style UI
- Full frontend–backend integration
- Clean, scalable project structure

---

## 🧰 Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router
- Axios
- Context API

### Backend
- Node.js
- Express.js
- MongoDB (Atlas)
- JWT Authentication
- bcrypt (password hashing)

---

## 🔐 Authentication Features

- User registration & login
- JWT-based authentication
- Secure logout
- Protected routes
- Change password functionality

---

## 👤 User Profile

- Profile section on dashboard
- Display name & email
- Editable display name
- Auto-generated avatar (identicon)
- Protected profile APIs

---

## 📊 Dashboard Features

- Crypto-style dark UI (glassmorphism)
- Create / view / delete trade notes
- Account statistics card
- Profile & security sections
- Responsive layout

---

## 📝 Log Files

A `logs/` directory is included with:
- Backend server logs
- Frontend interaction logs
- API testing logs
- Deployment readiness logs

These demonstrate successful execution and integration of all core features.
